# Project Requirements

## Project Title

**InsightAI – AI Student Skill Analyzer**

---

# Functional Requirements

The system shall provide the following functionalities:

## 1. Student Profile Collection

The chatbot shall allow students to provide:

- Technologies they know
- Programming languages
- Academic background
- Career interests
- Self-confidence level
- Learning goals

---

## 2. AI-Based Assessment

The chatbot shall conduct an interactive assessment by asking adaptive questions based on the student's responses.

The assessment will evaluate:

- Technical Knowledge
- Problem-Solving Ability
- Communication Skills
- Confidence Level
- Learning Mindset
- Career Readiness

---

## 3. Dynamic Question Generation

The chatbot shall dynamically generate follow-up questions using the Gemini API.

Questions should adapt according to:

- User's skills
- Previous answers
- Current assessment progress

---

## 4. Response Evaluation

The chatbot shall analyze every response and identify:

- Correct understanding
- Concept clarity
- Logical reasoning
- Confidence
- Areas requiring improvement

---

## 5. Student Skill Profile Generation

After the assessment, the chatbot shall generate a complete student profile containing:

- Technical strengths
- Technical weaknesses
- Skill ratings
- Confidence assessment
- Critical thinking analysis
- Learning mindset
- Career readiness

---

## 6. Recommendation System

The chatbot shall recommend:

- Topics to improve
- Technologies to learn next
- Suitable projects
- Learning roadmap

---

## 7. Assessment Report

The chatbot shall generate a final report including:

- Overall Rating
- Skill-wise Ratings
- Strengths
- Weaknesses
- Recommendations
- Growth Summary

---

# Non-Functional Requirements

The system should satisfy the following quality requirements:

- Fast response time
- User-friendly interface
- Modular backend architecture
- Scalable design
- Secure API key management
- Maintainable codebase
- Responsive frontend

---

# Assumptions

- Users have internet connectivity.
- Users provide genuine responses.
- Gemini API is available.
- AI responses are used for guidance only and are not official certifications.

---

# Constraints

- Assessment quality depends on user responses.
- Free-tier Gemini API limitations may apply.
- Initial version supports only Computer Science students.
- Internet connection is required.

---
