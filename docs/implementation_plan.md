# 4. REST API Design

## 1. Start Assessment API

### Endpoint

```text
POST /assessment/start
```

### Purpose

Creates a new assessment session and returns the first question.

### Request Body

| Field          | Type   |
| -------------- | ------ |
| student_name   | string |
| selected_skill | string |

### Response

| Field          | Type    |
| -------------- | ------- |
| session_id     | integer |
| first_question | string  |

---

## 2. Submit Answer API

### Endpoint

```text
POST /assessment/answer
```

### Purpose

Stores the student's answer and returns the next question.

### Request Body

| Field      | Type    |
| ---------- | ------- |
| session_id | integer |
| answer     | string  |

### Response

| Field         | Type    |
| ------------- | ------- |
| next_question | string  |
| completed     | boolean |

---

## 3. Generate Report API

### Endpoint

```text
POST /assessment/report
```

### Purpose

Generates the final assessment report after all questions are answered.

### Request Body

| Field      | Type    |
| ---------- | ------- |
| session_id | integer |

### Response

| Field                    | Type   |
| ------------------------ | ------ |
| overall_rating           | string |
| strengths                | list   |
| improvement_areas        | list   |
| learning_recommendations | list   |

# 6. Implementation Sequence

The project will be implemented in the following order:

### Phase 1 – Backend Setup

* Create FastAPI project.
* Configure project structure.
* Configure SQLite database.
* Configure Gemini API.

---

### Phase 2 – Database Development

* Create AssessmentSession table.
* Create AssessmentAnswer table.
* Test database connection.

---

### Phase 3 – Backend API Development

* Implement Start Assessment API.
* Implement Submit Answer API.
* Implement Generate Report API.

---

### Phase 4 – Gemini API Integration

* Generate assessment questions.
* Evaluate student responses.
* Generate final assessment summary.

---

### Phase 5 – Frontend Development

* Develop Home page.
* Develop Assessment page.
* Develop Report page.
* Develop reusable React components.

---

### Phase 6 – Frontend & Backend Integration

* Connect React application with FastAPI APIs.

### Phase 7 – Testing
